## Einführung
Dieses Statistics-Plugin erlaubt ZZZ.

## Installation
Um das Plugin nutzen zu können, müssen folgende Dateien installiert werden:

```bash
/opt/digiverso/goobi/plugins/statistics/plugin-statistics-ZZZ-base.jar
/opt/digiverso/goobi/plugins/GUI/plugin-statistics-ZZZ-gui.jar
/opt/digiverso/goobi/config/plugin_intranda_statistics_ZZZ.xml
```

Für eine Nutzung dieses Plugins muss der Nutzer über die korrekte Rollenberechtigung verfügen.

![Ohne korrekte Berechtigung ist das Plugin nicht nutzbar](screen1_de.png)

Bitte weisen Sie daher der Gruppe die Rolle `ZZZ` zu.

![Korrekt zugewiesene Rolle für die Nutzer](screen2_de.png)


## Überblick und Funktionsweise
Wenn das Plugin korrekt installiert und konfiguriert wurde, ist es innerhalb des Menüpunkts `Statistiken` zu finden.

![Nutzeroberfläche des Plugins](screen3_de.png)

ZZZ
